# robosphere-robotics-club
ROBOSPHERE
A modern, responsive website for ROBOSPHERE, a robotics club focused
on robotics, mechatronics, automation, and innovation.

Live Website:
 https://radhikainnovates.github.io/robosphere-robotics-club/

About the Project
ROBOSPHERE is a website designed to introduce the club, showcase its
areas of interest, share projects and events, and help visitors get in
touch.

The website has a technology-inspired design with a cyan and teal colour
palette, SVG icons, and responsive layouts.
Website Sections
- Home --- Introduction to ROBOSPHERE.
- About --- Highlights the club's focus areas:
  - Autonomous Systems
  - Mechatronics AI
  - Aerial Robotics
  - Hardware Prototyping
- Projects --- A section for showcasing robotics projects.
- Events --- A section for club events and workshops.
- Contact --- Contact information and an inquiry form.
- Footer --- Quick navigation links and additional club
  information.

Run Locally
1. Clone the repository:
   git clone https://github.com/radhikainnovates/robosphere-robotics-club.git
2. Open the project folder:
   cd robosphere-robotics-club
3. Open index.html in your browser, or use the Live Server
   extension in Visual Studio Code.
Deployment
This project is published using GitHub Pages.

To publish updates:
1. Save your changes.
2. Stage and commit the files.
3. Push the changes to the main branch.
4. Check the Actions tab in GitHub and wait for the Pages
   deployment to complete.
5. Visit the live website to verify the update.
Important Notes
- Keep file and folder names consistent with the paths used in
  index.html.
- GitHub Pages uses case-sensitive paths. For example,
  assets/icons/bot.svg and assets/Icons/bot.svg are different
  paths.
- When adding or renaming an SVG, make sure the file is committed and
  pushed to GitHub.
- Replace placeholder social media links and contact details with
  official club information before publishing.
